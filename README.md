# Calculator

A responsive calculator built with HTML, CSS and JavaScript.
Created as part of my CodeAlpha Frontend Development Internship.

## Features
- Addition, subtraction, multiplication and division
- Clear (C), delete (⌫) and percentage (%) buttons
- Decimal numbers, and handling of divide-by-zero
- Chained calculations (2 + 3 + 4)
- Keyboard support (numbers, operators, Enter, Backspace, Esc)
- Responsive design with hover and click effects

## Technologies
HTML5, CSS3, JavaScript (ES6)

## How to run
1. Download or clone this repository
2. Open `index.html` in any browser
